# `sentinel`: the final program

This directory holds the final program of SENTINEL: the four libraries of Labs 1 to 4 in one
process. `make` builds it as `build/sentinel` when each of the four libraries exists. At its
end it prints one line for each requirement, R1 to R6, with PASS or FAIL.

| Path | Who writes it |
|---|---|
| `main.c` | The course: the centre, with your four libraries |
| `supervise.c`, `include/sentinel/supervise.h` | The course: the supervisor of the sensor processes |
| `Makefile` | The course |

You write no file here. Lab 4 runs it: see Section 6 of
[`docs/lab4/lab4_brief.pdf`](../../docs/lab4/lab4_brief.pdf).
